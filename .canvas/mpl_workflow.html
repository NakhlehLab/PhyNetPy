MPL_reference.py — Two-Step Workflow

Maximum Pseudo-Likelihood scoring for phylogenetic networks

Input
GeneTrees
Input
Species → Allele Map
Input
Species Network
1 Gene-Tree Triplet Frequencies
compute_gene_tree_triplets(gene_trees, mapping)
Entry point. Sorts species labels and generates every unique 3-species combination.
For each triplet (X, Y, Z):
_compute_rho(X, Y, Z, gene_trees, mapping)
Loops over every gene tree. For each allele combination per species, calls _induced_triple to classify the topology as xy|z, xz|y, yz|x, or star. Stars split 1/3 to each resolution. Counts are normalized per-tree and summed.
Stores rho = (rho_xy_z, rho_xz_y, rho_yz_x) for the triplet.
Returns: GeneTreeTripletResult
.triplets  →  list of canonical (X, Y, Z) tuples
.rho_by_triplet  →  dict: triplet → (rho_xy_z, rho_xz_y, rho_yz_x)
gene_triplet_result passed as input
2 Species-Network Scoring
score_species_network_triplets(species_net, gene_triplet_result)
Entry point. Enumerates triplets from the network's leaves.
Creates a _TripleDPEngine for the species network. Identifies articulation nodes for state compression.
For each triplet (X, Y, Z):
engine.calculate_triple_probability((X,Y,Z))
Bottom-up DP over the network DAG. Tracks lineage states through tree nodes, reticulations, and branches. Returns P(XY|Z).
Calls again with (X,Z,Y) to get P(XZ|Y). Derives P(YZ|X) = 1 − P(XY|Z) − P(XZ|Y).
Accumulates log pseudo-likelihood:
total += rho_i × log(p_i)   for each resolution where rho > 0.
Returns: SpeciesNetworkTripletResult
.triplets  →  list of (X, Y, Z) tuples
.probs_by_triplet  →  dict: triplet → (P(XY|Z), P(XZ|Y), P(YZ|X))
.log_pseudo_likelihood  →  float (the final MPL score)
C MPL Class — Convenience Wrapper
MPL(species_net, gene_trees, mapping)
Constructor calls Step 1 internally and caches the result.
mpl.score()
Runs Step 2 logic in a loop over triplets, returns the total log pseudo-likelihood as a float.
MPL.from_nexus(gt_file, st_file, mapping)
Alternate constructor that reads Nexus files before calling the standard constructor.
