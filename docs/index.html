Phylogenetic network research toolkit

Build, score, and infer phylogenetic networks in Python.

PhyNetPy provides research-grade data structures, simulation tools, and search methods for phylogenetic networks, including a unified inference API and accelerated scoring paths in the 0.5.0 release.

Read the docs See what is new

Unified Inference

Two verbs, infer and score, cover the MPL, MCMC-GT, MP-Allop, and biallelic-marker methods. Which one runs is set by the data, model, and criterion you pass.

Network Moves

Explore reticulation-aware topology moves, adaptive proposal kernels, and search drivers for network inference experiments.

Fast Scoring

Optional Cython engines accelerate MPL triplet scoring and gene-tree MSC scoring while preserving pure-Python fallback behavior.

Version 0.5.0

Faster, more reliable phylogenetic-network search

PhyNetPy 0.5.0 adds the public phynetpy.infer API, Cython dynamic-programming engines, adaptive proposal kernels, and correctness fixes for reticulation moves.

  • Cython MPL and gene-tree MSC scoring engines.
  • Adaptive MCMC-GT proposal kernel with per-move statistics.
  • Reticulation move fixes that preserve gamma invariants.

For Researchers

Use PhyNetPy to prototype network inference methods, test topology moves, compare scoring strategies, and run reproducible simulations.

  • MPL
  • MSC scoring
  • Reticulation moves
