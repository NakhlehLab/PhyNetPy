Phylogenetic network research toolkit

Build, score, and infer phylogenetic networks in Python.

PhyNetPy provides research-grade data structures, simulation tools, and search methods for phylogenetic networks, including a unified inference API, explicit biological units, and accelerated scoring paths.

Read the docs See what is new

Unified Inference

Two verbs, infer and score, cover the MPL, MCMC-GT, MP-Allop, and biallelic-marker methods. Which one runs is set by the data, model, and criterion you pass.

Network Moves

Explore reticulation-aware topology moves, adaptive proposal kernels, and search drivers for network inference experiments.

Fast Scoring

Required Cython engines accelerate graph operations, MPL triplet scoring, gene-tree MSC scoring, and sequence-likelihood kernels.

Version 0.6.0

Explicit units and one inference API

PhyNetPy 0.6.0 consolidates inference around infer, score, and simulate, and makes branch-length units explicit throughout biological calculations.

  • Typed data, model, and criterion axes for every method.
  • Exact MSNC biallelic-marker simulation.
  • Population-specific theta and population-genetics helpers.

For Researchers

Use PhyNetPy to prototype network inference methods, test topology moves, compare scoring strategies, and run reproducible simulations.

  • MCMC
  • MPL
  • MSC scoring
  • Reticulation moves
