State

class State

Accept/reject bookkeeping for the Metropolis-Hastings and annealing drivers, around one live model. A proposal is a :class:`Move` executed in place on ``model.network``. Rejection undoes the move in place. Acceptance records the proposal's score as the accepted score and nothing else: the live network simply stays as it is. There is no second copy of the network, so accepting a move costs nothing, and scorers that cache topology by network identity (see ``MPLScorer``) keep their caches across acceptances. The one invariant this rests on: :meth:`likelihood` returns the cached accepted score and never re-scores the live network, because the live network may be mid-proposal when it is read. Module Functions

network_invariants_routine(model: Model) -> bool

Validate that a network satisfies phylogenetic invariants. Checks: 1. Exactly one root (in-degree 0, out-degree >= 2) 2. Every leaf has (in=1, out=0) 3. Every reticulation has (in=2, out=1) 4. Every other internal node has (in=1, out >= 2) 5. The graph is a DAG (acyclic)

Parameter Type Description
model A Model whose ``network`` attribute is the phylogenetic network.
Returns: True when all invariants hold, False otherwise.
