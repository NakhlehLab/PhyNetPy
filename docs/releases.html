Released May 12, 2026

PhyNetPy 0.5.0

PhyNetPy 0.5.0 is focused on faster and more reliable phylogenetic-network search. The release keeps existing public imports backward compatible while adding a curated inference front door.

Highlights

  • Unified inference API: phynetpy.infer re-exports supported inference workflows.
  • Cython acceleration: MPL dynamic programming and gene-tree MSC scoring now have optimized engines.
  • Adaptive proposal kernels: MCMC-GT tracks per-move statistics and can tune proposal weights during search.
  • Simulated annealing improvements: geometric, linear, and plateau-aware schedules are available.
  • Reticulation correctness fixes: topology moves preserve gamma sum-to-one invariants.

Install

pip install phynetpy

The repository also includes the full Markdown release notes at RELEASE_NOTES_0.5.0.md and the running changelog at CHANGELOG.md.
