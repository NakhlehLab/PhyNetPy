Released October 30, 2026

PhyNetPy 0.7.0

PhyNetPy 0.7.0 adds DIMPLE, a divide-and-conquer pipeline for inferring large networks from a tree of blobs, and a joint reticulation-and-tree dissimilarity for comparing networks. Network edits are now transactional, and seeded searches reproduce across processes.

Highlights

  • DIMPLE: infer_dimple partitions a tree of blobs, infers each subset under MSC pseudo-likelihood, merges, and grafts.
  • Joint dissimilarity: joint_dissimilarity scores matched reticulations and the reticulation-free remainders separately.
  • Hybrid-ancestry error: the balanced HAE of an estimate against the truth, plus distinct displayed-tree enumeration.
  • Transactions: journaled, nestable, in-place undo for network edits; no topology move copies the network.
  • Reproducibility: process-independent node and edge hashes, and annotated Newick that round-trips.

Install

pip install phynetpy
