Released August 10, 2026

PhyNetPy 0.6.0

PhyNetPy 0.6.0 consolidates inference around three typed axes and makes biological units explicit. This is a breaking alpha release; review the migration notes before upgrading from 0.5.x.

Highlights

  • One inference API: infer, score, and simulate dispatch over data, model, and criterion.
  • Explicit units: branch lengths are tagged and converted instead of being interpreted implicitly.
  • Exact marker simulation: every biallelic site receives an independently sampled MSNC genealogy.
  • Population parameters: fixed per-branch theta values are available for simulation and scoring.
  • Population genetics: validated allele-count and pulse-admixture containers are now public.

Install

pip install phynetpy

The repository also includes the full Markdown release notes at RELEASE_NOTES_0.6.0.md and the running changelog at CHANGELOG.md.
