PhyNetPy 0.6.0 Released

The 0.6.0 release consolidates inference around typed data, model, and criterion axes; introduces explicit branch-length units; and adds exact marker simulation and population-genetics helpers.

PhyNetPy 0.5.0 Released

The 0.5.0 release introduces the unified phynetpy.infer API, Cython acceleration for core scoring workflows, adaptive MCMC-GT proposal kernels, and important reticulation move fixes.
