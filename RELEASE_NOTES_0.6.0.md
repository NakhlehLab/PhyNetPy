# PhyNetPy 0.6.0

*Release date: 2026-08-10*

PhyNetPy 0.6.0 consolidates inference around the `infer`, `score`, and
`simulate` verbs and makes biological units explicit throughout the package.
It is a breaking alpha release: users of 0.5.x should review the migration
notes before upgrading.

## Highlights

- A typed inference API built around data, biological model, and statistical
  criterion axes.
- Explicit branch-length units and conversion between substitutions per site
  and coalescent units.
- Exact biallelic-marker simulation using an independently sampled MSNC
  genealogy at each site.
- Population-specific theta values for simulation and fixed-network scoring.
- New `PopulationData` and `AdmixtureGraph` population-genetics helpers.
- Corrected and accelerated nucleotide substitution models.
- A smaller public API after removal of unused model-building and traversal
  abstractions.

## Breaking changes

### Inference entry points

Use the public facade:

```python
from phynetpy.infer import infer, score, simulate
from phynetpy.data import GeneTrees
from phynetpy.models import MSC
from phynetpy.criteria import PseudoLikelihood

data = GeneTrees.from_file("gene_trees.nex", mapping)
result = infer(data, model=MSC(), criterion=PseudoLikelihood())
```

Legacy command modules and the unused component/visitor model-building layer
have been removed. The engine implementations remain private modules for
internal development and focused testing.

### Branch-length units

Biological calculations no longer guess what network branch lengths mean.
Tag networks explicitly:

```python
from phynetpy.models import BranchLengthUnit

network.set_branch_length_unit(BranchLengthUnit.COALESCENT_2N)
```

Use `COALESCENT_2N` for gene-tree topology workflows and
`SUBSTITUTIONS_PER_SITE` for timed sequence and marker workflows.
`convert_network_branch_lengths` converts between them using theta.

### Theta naming

The population parameter is now consistently called `theta`:

```python
MSC(theta=0.02)
```

Replace the former `coal=` keyword in MSC and marker APIs with `theta=`.
Fixed `branch_thetas` are supported by simulation and fixed-network scoring;
topology-changing sequence and marker MCMC reject them until proposal support
is implemented.

### Marker simulation

Biallelic markers are now generated by sampling an independent genealogy at
each site under the MSNC and evolving a two-state CTMC down it. This is a model
change, so simulations using the same seed will not reproduce 0.5.x output.

### Substitution models

GTR-family construction, transition matrices, parameter validation, and model
signatures were corrected. In particular, K80/HKY/TN93 now take their standard
kappa parameterizations. See `CHANGELOG.md` for the complete migration table.

## New population-genetics helpers

`PopulationData` stores alternate and callable allele counts without treating
missing genotypes as reference alleles. `AdmixtureGraph` validates pulse
admixture semantics on a PhyNetPy network. These are analysis helpers rather
than inference-axis data types.

## Packaging and compatibility

- Supported Python versions: 3.9 through 3.14.
- Cython extensions are required; wheels avoid a local compiler, while source
  installs need a working C compiler.
- Package metadata is defined in `pyproject.toml`; `src/_version.py` is the
  version source of truth.

## Verification

The release process runs the default suite, slow recovery/stress tests,
PhyloNet numerical cross-checks when their external dependencies are present,
package build validation, and clean-install smoke tests.

For the exhaustive list of changes and migration details, see
[`CHANGELOG.md`](CHANGELOG.md).
