PhyNetPy

PhyNetPy is a Python library for phylogenetic network inference and analysis, providing improved methods from PhyloNet as well as a framework for developing new Bayesian/simulation-based methods and structures.

The current version is v0.5.0 (see `CHANGELOG.md` for the full history). The
public inference API lives in `phynetpy.infer` -- see `examples/quickstart.py`
to get started, or `Guides/INSTALLATION_GUIDE.md` for installation
instructions.

A tutorial and further instructions on how to use PhyNetPy will be made available on our website, https://phylogenomics.rice.edu
